# @century/sim-worker

Century's versioned simulation worker boundary.

- `protocol` (root export) — protocol version 4 commands/events, immutable snapshot
  types, parsing/validation, and pure selectors. App-safe; no simulation import.
- `host` — `SimulationHost`, which owns the authoritative world and applies
  commands only between complete ticks.
- `snapshot` — snapshot builder from authoritative state. E1 adds derived production
  capacity, need tiers, household cash/wage data, market capacity, close balances, and
  monthly labels; M7a adds bounded annual reports.
- `fiscalPreview`, `reports`, `explanations`, `actionHistory` — pure E1 selectors. They
  operate only on snapshots and never read the world.
- `persistence` — gzip/base64 storage codec for canonical save strings.
- `node` — Node `worker_threads` entry used by the M7 proof of concept.

## Scripts

```bash
pnpm -F @century/sim-worker build
pnpm -F @century/sim-worker typecheck
pnpm -F @century/sim-worker scenario:build   # requires @century/data build
pnpm -F @century/sim-worker poc              # off-main-thread Node proof
```

The browser bundle is generated by `packages/app/scripts/build-worker.mjs`; the
validated eight-polity scenario is committed in `src/generated/m5Scenario.ts`.
